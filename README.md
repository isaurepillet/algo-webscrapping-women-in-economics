# Women in Economics — Research Data Collection

**Research assistant project supervised by Emmanuelle Taugourdeau**

This repository contains code developed for a research project on **women's representation and career patterns in academic economics and finance**, with a focus on France in comparison with other European countries.

## Project scope

The research required building and cleaning a researcher-level dataset from online academic sources. The workflow combines automated data collection with extensive harmonisation and entity matching.

## Data workflow

The Python notebook includes work on:

- collecting researcher information from online academic sources;
- web scraping and automated data extraction;
- cleaning and standardising names, affiliations and research-centre information;
- matching researchers across sources;
- constructing variables used to study gender representation and academic careers;
- producing descriptive statistics for the research project.

Sources used in the broader project include **RePEc/IDEAS** and academic web data.

## Tools

Python · Jupyter · pandas · web scraping · data cleaning · entity matching

## Research context

The code was developed as part of a research-assistant position. The repository contains the shareable data-collection code; research outputs and non-public working data are not included.
